The Mason Week · the shared-event problem

How would Tufte draw one event attended by some combination of four people?

The four-column day view is excellent for the question “what is each person doing?” — position is time, height is duration, one column per person. It breaks on the question “who is doing this together?” The current build answers it by drawing a shared event up to four times: a full card in an arbitrary “owner’s” column and a dashed ghost in every attendee’s column. Tufte’s objection isn’t aesthetic — it’s that this duplicates data ink, makes the eye reconcile four boxes into one fact, and invents an “owner” distinction that isn’t in the data. A shared dinner has no owner.

The data is really one interval plus a set of attendees — a subset of four people, so one of sixteen combinations. Tufte would keep the columns for solo time but draw each shared event once, and make the combination itself the thing you read. Below: the recommended treatment, then a head-to-head on the hardest case (a non-contiguous pair).

Today — solo time in columns, shared time tied across them

Personal events keep their person-colored column block. A shared event is one neutral object: faint blocks under exactly the attending columns, joined by a labeled bracket, with a four-cell attendance glyph (●●●○ = Jenny, Andrew, Sebastian, not Oscar). No ghosts, no owner, no duplication — and a non-contiguous pair like Jenny + Oscar reads honestly.

What Tufte changes about shared events

1. Draw it once. One event, one labeled object — not an owner card plus three ghosts. Erase the redundant ink.
2. Kill the “owner.” The owner/attendee split isn’t in the data; a shared event is symmetric. Neutral color says “ours,” person color says “mine.”
3. Make the combination legible. Which columns are filled is the attendee set — including non-contiguous sets — backed by the four-cell glyph for certainty.
4. Keep the columns, but only for what they’re good at. Solo events still scan down a person’s column; shared events become a relation drawn across columns, not copies sitting in them.
5. Layer “ours” behind “mine.” Shared events recede in a warm gray so each person’s own commitments pop — macro (the family’s shared spine) and micro (my day) at once.

Tradeoff: the bracket’s tie-line crosses over non-attending columns, which could imply inclusion; the empty columns and the glyph keep it honest, but in a crowded hour the “shared lane” variant (third panel above) trades the spatial tie for a cleaner separation of mine vs ours.
